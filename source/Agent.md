Sheet-to-Doc 不只有"打开软件、点按钮"的形态。**AI 技能版**把同样的文档生成能力，做成一项可以装进 [WorkBuddy](https://www.workbuddy.cn/) AI 助手的技能（Skill）：不用打开新界面、不用记命令，把 Word 模板和数据表交给它，用一句话说清需求，几百份 Word 就批量出炉。

:::{note}

:::

## 准备好三样东西，交给技能

在 WorkBuddy 里使用时，你不需要敲命令。只要把下面三样东西准备好，通过对话交给 AI 助手（在对话中上传为附件，或告诉 AI 它们在当前工作目录里的路径），剩下的由技能完成。

### 1. Word 模板（.docx）

- 一份 `.docx` 文件，在要填数据的位置写好占位符，写法与其他版本完全通用，详见 [Word 模板](WordTemplate.md)。
- 把模板文件发给 AI，或告诉 AI 它的路径。
- 只支持 `.docx`；旧版 `.doc` 请先用 Word 另存为 `.docx`。

### 2. 数据文件

一个文件，支持 **Excel（.xlsx）、CSV、JSON、JSONL**，数据准备的总体要求与其他版本一致，详见 [数据和图片准备](ExcelData.md)：

- 第一行是表头，列名要和模板占位符**完全一致**（大小写敏感），之后每行是一条数据；
- 表头不能整行为空，不建议包含空格或 `@ - ( ) [ ] { } # $ % |` 等特殊字符；
- 空行会被自动跳过；
- **Excel** 默认读第一个工作表，可指定工作表名或索引；表头不在第 1 行时可指定表头行；日期会统一成 `YYYY-MM-DD`，数字保持数字类型（货币、百分比等格式化依赖这一点）；
- **CSV** 必须是 UTF-8 编码；CSV 里所有值都是字符串，因此 `currency`、`percentage` 等数字过滤器不会生效——需要数字格式化时请改用 `.xlsx`；
- **JSON / JSONL** 保留原始类型，支持一层点号嵌套字段。

把数据文件发给 AI，或告诉 AI 它的路径。

### 3. 图片（可选，仅模板用到图片时）

只有模板里写了图片占位符时才需要准备图片：

- 把所有图片放进**同一个文件夹**；技能只扫描该文件夹的第一层，不递归子目录。
- 数据列里写图片的**文件名（含后缀）**，例如 `watch.png`；模板里对应写 `{@图片字段 | _inline_image:宽:高}` 或 `{@图片字段 | _block_image:宽:高}`（宽高单位为厘米，图片占位符需单独占一行）。占位符写法详见 [Word 模板](WordTemplate.md)。
- 支持格式：`.png` `.jpg` `.jpeg` `.gif` `.bmp`；按文件名匹配，不区分大小写。
- 单张建议小于 1 MB（过大拖慢生成），单张超过 20 MB 会报错；目录内不能有重名图片（含仅大小写不同）。
- 不支持远程图片 URL。
- 把图片文件夹交给 AI，并说明哪个文件夹是图片目录。

:::{note}
**二维码不需要准备图片。** 在模板里写 `{@字段 | _qrcode:宽:高}`，技能会现场生成二维码，内容取自对应的数据列。
:::

### 交给 AI 时怎么说

准备好后，像这样交代即可（文件已在对话中上传，或给出路径）：

> "使用 sheet-to-doc-agent-skill，做：用 `在职证明.docx` 这个模板和 `staff.xlsx`，给每个人生成一份在职证明，文件名用姓名。"

如果用到了图片，再补一句图片目录在哪：

> "照片都在 `./photos` 目录里，数据列 `照片` 写的是文件名。"

:::{hint}
不确定列名、图片名对不对？让技能先做一次"比对数据"：它会识别模板占位符、读取数据行数与字段、指出缺失/多余，并预览前几行，同时检查图片引用。确认无误后再批量生成，避免一上来就跑出几百份错文档。
:::

## 它能做什么

AI 技能版复用 Sheet-to-Doc 的全部文档能力，模板写法与其他版本完全一致（见 [Word 模板](WordTemplate.md)）：

支持 **4 种数据源**：Excel（可指定工作表）、CSV、JSON、JSONL，数据准备要求与其他版本一致，详见 [数据和图片准备](ExcelData.md)。


## 两种生成模式

与其他版本相同，AI 技能版也支持两种模式（参见 [使用步骤](Usage.md)）：

- **模式一：每行一份独立文档**——表格有多少行就生成多少份 Word，适合工资条、荣誉证书、邀请函、员工合同、缴费通知、收据。
- **模式二：全部数据汇入一份文档**——用循环标记包住内容，所有数据写进同一个 Word 文件，自动续页，适合人员花名册、订单明细、项目汇总报表、批量标签页。

## 工作流：四步走

AI 技能版在对话中遵循"先预览、再样本、后全量"的稳妥流程，避免一上来就跑出几百份错文档：

1. **巡检模板**——识别模板中的占位符（数据 / 循环 / 判断 / 图片），一次看清；
2. **比对数据**——读取数据行列数与字段，指出缺失与多余，展示前几行预览供核对；
3. **生成 1 份样本**——先用第一行数据渲染一份，确认版式、字号、图片位置都对了再继续；
4. **批量出全量**——确认后去掉限制，一次生成全部文档，按规则自动命名并打包输出。

一段真实的对话：

```text
用户：使用 sheet-to-doc-agent-skill，做：用这个 Word 模板，
      把 data.xlsx 里每个人生成一份合同，文件名用姓名。

AI：已识别模板占位符 6 个 ✓
    数据共 248 行，字段校验通过 ✓
    预览前 3 行：张三 / 北京 / 2026-01-05
                李四 / 上海 / 2026-01-06
                王五 / 深圳 / 2026-01-08
    先生成 1 份样本确认版式？(Y/n)

用户：好的。

AI：样本已生成，版式确认无误，开始批量生成……
    ✓ 已生成 248 份文档 → ./output
    ✓ 耗时 6.2 秒 · 0 个错误
```

调用技能名：`sheet-to-doc-agent-skill`。

:::{hint}
默认先渲染样本，出错即中止且不写出半成品；也可以选择跳过出错的行继续生成，出错原因清晰可读。
:::

## 一个例子

准备好数据表和写好占位符的 Word 模板（占位符写法见 [Word 模板](WordTemplate.md)）：

- 数据 `staff.xlsx`：第一行是列名（姓名 / 部门 / 入职日期），之后每行是一个人的信息；
- 模板 `在职证明.docx`：在对应位置写好 `{姓名}`、`{部门}`、`{入职日期}`。

然后对 AI 说：

> "使用 sheet-to-doc-agent-skill，做：用这个模板和数据表，给每个人生成一份在职证明，文件名用姓名。"

即可得到 `陈晓.docx`、`林悦.docx`……每份文档的占位符都被替换为对应行的真实数据。

## 隐私与安全

- 技能本身**不收集、不留存**你的文档数据；
- 在 WorkBuddy 中使用时会调用大模型，数据经由 WorkBuddy 平台处理，遵循 WorkBuddy 隐私条款；
- 默认**样本先行**，第一行渲染失败即中止，不写出半成品；也可选择跳过出错的行继续生成；
- 生成时可选**文档加密**（打开密码），敏感文件可直接加锁。

详见 [数据安全](Safety.md) 与 [隐私政策](privacy.md)。
